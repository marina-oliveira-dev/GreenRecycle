**Green Recycle**

**Sobre o projeto:**
O Green Recycle é um aplicativo Android desenvolvido em equipe como projeto acadêmico do curso de Ciência da Computação.
O objetivo é promover a educação ambiental por meio de um aplicativo que auxilia e explica o que cada lixo recicla (coleta seletiva) e o descarte correto desses resíduos. Além dos pontos de coleta disponíveis na cidade.

**Tecnologia usadas:**
- Kotlin
- Android Studio
- Jetpack Compose

**Desenvolvimento:**
Projeto acadêmico semestral, desenvolvido colaborativamente por cinco estudantes de Ciência da Computação.
